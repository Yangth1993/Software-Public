AUTHORITY

助力参数、车辆关键配置和用户设置以 RT1172/RT1046 Flash 为权威副本。

PORTABILITY

换 RTOS 时保留 Action、校验、状态和 ViewModel，只替换 storage / transport / device adapters。

NO PROJECT MACRO SPRAWL

RT1046 决定整机断电；F133 负责把 GUI、文件、Wi-Fi 和语音资源安全收拢。
