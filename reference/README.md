## 归档原则

- 优先采用芯片厂商和上游项目官方来源。
- 同时记录来源、版本/提交、获取日期、许可证或访问限制。
- 标有秘密、Confidential、NDA 或禁止复制的资料不作为公开资料归档或再分发。
- “网页可访问”不等于“允许复制到工程仓库”。
